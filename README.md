# Hopetize · Twingle-Formular im Hopetize-Design

Eigenes Stylesheet für das Twingle-Spendenformular der Weihnachtsaktion 2026 von Hopetize Kinderkrebshilfe e. V.

Einbindung in twingleMANAGER: Projekt → Darstellung → „Eigene CSS-Datei (URL)“ mit der jsDelivr-URL eines Tags, z. B.

```
https://cdn.jsdelivr.net/gh/dxnielhrf/hopetize-twingle-style@v1/hopetize-twingle.css
```

Änderungen: Datei anpassen, neuen Tag setzen (v2, v3 …) und die URL in Twingle auf den neuen Tag umstellen.
